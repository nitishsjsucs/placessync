# Figma

No Figma file exists for PlacesSync. The eight UI kit components were built from the design tokens in `src/client/ui/tokens.css` and the keyboard and ARIA contracts in SPEC 14.2, not from Figma frames.

The components came first, so "built from Figma designs" cannot become true for this version: frames drawn now would document the built components, not be the designs they were built from. The accurate wording is "built from a documented design-token and ARIA contract spec". If a Figma file is made later, it can be described as documenting the components ("documented in Figma"), and its URL and a frame-to-component map belong in the table below.
